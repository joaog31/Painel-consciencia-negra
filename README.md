# Exposição Escolar • Dia da Consciência Negra
## Mural Digital das Personalidades Negras

Projeto web estático desenvolvido para exposição escolar comemorativa do Dia da Consciência Negra. O projeto é composto por **10 páginas HTML totalmente isoladas**, sem links cruzados ou menus, projetadas especificamente para leitura via celular através de **QR Codes individuais** afixados no mural físico da escola.

## 🎨 Características do Projeto

- **Arquitetura 100% Isolada:** Não possui `index.html`, nem barras de pesquisa, menus de navegação ou botões de "voltar". Cada página é uma placa memorial autônoma.
- **Mobile-First & Responsivo:** Interface otimizada especificamente para telas de smartphones (320px a 600px+), com alta legibilidade em ambientes de exposição.
- **Estética Cultural:** Paleta escura elegante (tons de carvão/terra `#12100e` e `#1f1b18`), cartão centralizado com detalhes e bordas em dourado e âmbar (`#d4af37`), tipografia refinada (*Playfair Display* e *Plus Jakarta Sans*).
- **Estilo Unificado:** Todos os arquivos compartilham o `style.css` externo para fácil manutenção.
- **Placeholders Prontos:** A pasta `imagens/` já vem com todas as imagens JPG decorativas e informativas de alta resolução (10 retratos de personalidades e 3 obras de arte em destaque de Ayrson Heráclito), prontas para substituição pelas fotografias definitivas.

## 🖼️ Como Substituir as Fotos

Basta salvar as fotos reais na pasta `imagens/` com os mesmos nomes listados na tabela acima:
- **Retratos das personalidades:** proporção 1:1 quadrada (ex: 800x800px) com o rosto centralizado.
- **Obras de Ayrson Heráclito:** `ayrson-obra-sacudimento.jpg`, `ayrson-obra-juntos.jpg` e `ayrson-obra-irawo-bori.jpg` (proporção aproximada 16:10 ou 4:3 em modo paisagem, ex: 960x600px).
